# CrestRaft

CrestRaft is a distributed, real-time data processing platform that enables auto-scaling, microservices architecture, and event-driven gateway functionality.

With CrestRaft, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/CrestRaft.git`
2. `cd CrestRaft`
3. Install in editable mode: `pip install -e .`

## Configuration

CrestRaft is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
